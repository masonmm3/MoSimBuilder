# Security Policy

## Supported Versions

MoSimulator only supports the listed versions on its itch.io website at https://mostudios.itch.io/mosimulator

| Version | Supported          |
| ------- | ------------------ |
| 25.3.x   | :white_check_mark: |
| 25.2.x  | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

Please include as much detail as possible. Some important things to note when reporting a vulnerability
1. A vuln is NOT a bug, not something that shouldn't happen, but something that could cause the game to break for other people, and even a RCE (remote code execution), which is one of the most critical vulns
2. These types of issues need to be reported right when you see them, and if they are disclosed publicly, it makes the game way more vulnerable to attacks and exploitation
3. We will make sure to respond within 72 hours of receiving the notification about a security vulnerability being reported, and will fix it within 2 weeks of receiving the notification of the vulnerability
4. We thank you for cooperating with us and reporting this issue within our game!
